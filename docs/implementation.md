# Windows 首版

本版为猫主人提供照片和手动两种建猫入口。保存外观后，黑猫在其他应用前模拟鼠标与键盘动作。上浮的标签来自单次按键。

## 实现与验收

- 在 CatEditor 和 PhotoPalette 中读取本地照片，提供可校正的毛色与局部标记。用两种入口编辑同一外观，保存后重开仍可修改。
- 在 PetView 中按桌宠坐标绘制猫、键盘与鼠标。普通键有对应落点，连续输入独立淡出，鼠标悬停在猫头时会眯眼。
- 在 PetWindow 中适配透明、不夺焦点的 Windows 窗口和系统键鼠输入。托盘可暂停、隐藏键名、调整位置和退出。
- 从干净检出编译，检查外观保存、透明渲染、输入映射和窗口生命周期，再公开发布源码。

主要边界包括非英文输入法的物理按键、连续高速输入、负坐标的副屏、误选损坏的照片、只读或损坏的设置文件。发行前应另外在实际使用的屏幕缩放和输入设备上试用。
